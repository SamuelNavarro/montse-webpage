# Montse García Juanola — website

Static site, no build step.

## Deploy to GitHub Pages
1. Create a new GitHub repository (e.g. `montse-garcia`).
2. Upload `index.html` and the `images/` folder to the repository root.
3. Go to **Settings → Pages**, set Source to **Deploy from a branch**, branch `main`, folder `/ (root)`, and save.
4. The site goes live at `https://<your-username>.github.io/<repo-name>/` within a minute or two.

To replace a photo, overwrite the file in `images/` with the same name.
